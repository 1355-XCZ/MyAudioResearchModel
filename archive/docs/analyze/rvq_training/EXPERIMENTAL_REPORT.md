## 1. 实验配置

### 1.1 模型结构

```python
# 分组RVQ配置
feature_dim: 768              # emotion2vec特征维度
num_groups: 12                # 分组数
group_dim: 64                 # 每组维度 (768/12=64)
num_fine_layers: 16           # 每组残差量化层数
fine_codebook_size: 128       # 每层码本大小
enable_skip: bool = True      # 启用SKIP机制

# 理论最大容量
```

## 8. 讨论

### 8.1 为什么是94.72%而非98-99%？

**可能原因**：
1. **16层配置容量**：虽然有1344 bpf理论容量，但实际学习能力受限
2. **EMA模式特性**：保守的更新策略（decay=0.99）
3. **100h数据量**：相对于192层可能需要更多数据
4. **特征复杂度**：emotion2vec特征可能包含难以量化的信息

**对比分析**：
- 8层配置（测试）: 3 epochs → 84.32%
- 16层配置（完整）: 22 epochs → 94.72%
- 提升: +10.4%

### 8.2 94.72%是否足够？

**评价**: ✅ **优秀，足以发表**

**理由**：
1. **超过目标**：94.72% > 90%目标
2. **码本完美**：100%利用率，125/128困惑度
3. **训练稳定**：收敛良好，无过拟合
4. **文献对比**：音频VQ研究中，90%+的还原率已是高水平
