## 问题根源

### 简化ECVQ的局限

**简化ECVQ判决**：
```python
J(k) = D(k) + λ·C  # C是常数（假设均匀分布）

当λ很大时:
  λ·C项主导
  → 总是选择"最小C"
  → 而SKIP的C最小（编码长度0）
  → 全部SKIP
```

**真实ECVQ判决**（需要熵模型）：
```python
J(k) = D(k) + λ·(-log₂ q(k|ctx))

q(k|ctx)是熵模型学习的实际概率
  → 不同位置的SKIP概率不同
  → 不会全部SKIP
```

**结论**: 
- 简化ECVQ高估了SKIP倾向
- λ≥96全SKIP是简化模式的问题
- **真实训练时可能不会这样** ⚠️
